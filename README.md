# CaptureAny Desktop Releases

Official public binary distribution channel for CaptureAny desktop applications.

### Supported Platforms
- **macOS Apple Silicon (arm64)**: DMG & Portable ZIP
- **macOS Intel (x64)**: DMG & Portable ZIP
- **Windows 64-bit (x64)**: Setup Installer & Portable ZIP
- **Windows 32-bit (x86)**: Setup Installer & Portable ZIP

Visit [captureany.com](https://captureany.com) for official documentation, features, and web application.
